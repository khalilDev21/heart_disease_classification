START HERE — HEART DISEASE CLASSIFICATION PROJECT

OPEN THE PROJECT
1. Extract the ZIP file if needed.
2. Open the heart_disease_classification folder in VS Code.
3. Open Terminal > New Terminal in VS Code.

RUN THE APP
The trained model is included. Create and activate an environment, install the project packages, then launch the app:

   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   streamlit run app/streamlit_app.py

REPRODUCE THE FULL WORKFLOW (OPTIONAL)
Run these commands from the project root to download the data, retrain all models, and generate explanations:

   python src/download_data.py
   python src/train.py
   python src/explain.py

FIND THINGS
- docs/PROJECT_MAP.md — folder map, commands and output files.
- reports/project_report.md — report template; add only metrics from outputs/model_comparison.csv.
- docs/DEPLOYMENT.md — Streamlit Community Cloud settings and current GitHub path.

The app is for education and research only. It is not a diagnostic tool or a substitute for professional medical advice.
